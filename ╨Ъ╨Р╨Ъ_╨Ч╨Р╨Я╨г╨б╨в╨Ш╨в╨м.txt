ФАЙЛЫ В ЭТОЙ ПАПКЕ:
  tracker.html       — само приложение
  start_server.py    — сервер (запускать на компьютере)
  КАК_ЗАПУСТИТЬ.txt  — эта инструкция

════════════════════════════════════════════════════════
ШАГ 1 — УСТАНОВИ PYTHON (если ещё не установлен)
════════════════════════════════════════════════════════

  Скачай с официального сайта: https://python.org/downloads
  Версия 3.8 или новее. При установке поставь галочку
  "Add Python to PATH"

  Проверь что установлен — в командной строке:
    python --version   (должно показать Python 3.x.x)

════════════════════════════════════════════════════════
ШАГ 2 — УСТАНОВИ БИБЛИОТЕКУ ДЛЯ QR-КОДА
════════════════════════════════════════════════════════

  Один раз, в командной строке (cmd):
    pip install qrcode

  Если не работает:
    python -m pip install qrcode

════════════════════════════════════════════════════════
ШАГ 3 — ЗАПУСТИ СЕРВЕР
════════════════════════════════════════════════════════

  Способ А (просто):
    Дважды кликни на файл  start_server.py

  Способ Б (через командную строку):
    cd путь_до_этой_папки
    python start_server.py

  В окне появится QR-код и адрес вида:
    http://192.168.1.XXX:8080/tracker.html

════════════════════════════════════════════════════════
ШАГ 4 — ОТКРОЙ НА ТЕЛЕФОНЕ
════════════════════════════════════════════════════════

  ! Телефон и компьютер должны быть в одной Wi-Fi сети !

  Вариант А — QR-код:
    Отсканируй QR-код в окне сервера камерой телефона
    или любым QR-сканером

  Вариант Б — вручную:
    Открой Chrome на телефоне
    Введи адрес из окна сервера (192.168.1.XXX:8080/tracker.html)

════════════════════════════════════════════════════════
ШАГ 5 — ДОБАВЬ НА РАБОЧИЙ СТОЛ (необязательно)
════════════════════════════════════════════════════════

  В Chrome на телефоне нажми  ⋮  (три точки)
  → "Добавить на главный экран"
  → Появится иконка как у обычного приложения

════════════════════════════════════════════════════════
ВАЖНО
════════════════════════════════════════════════════════

  • Сервер должен быть запущен пока ты пользуешься
    приложением через браузер

  • Если добавил на рабочий стол — приложение работает
    даже без сервера и без интернета (данные в телефоне)

  • Данные хранятся в памяти телефона (localStorage)
    и не пропадают при перезагрузке

  • Для остановки сервера закрой окно или нажми Ctrl+C

════════════════════════════════════════════════════════
ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
════════════════════════════════════════════════════════

  Ошибка "порт занят":
    Измени PORT = 8080 на PORT = 8081 в файле start_server.py

  Телефон не открывает страницу:
    - Проверь что оба устройства в одной Wi-Fi
    - Проверь брандмауэр Windows: разреши Python в сети
      (Пуск → Брандмауэр → Разрешить приложение → Python)

  QR не отображается:
    Введи адрес вручную из окна сервера
